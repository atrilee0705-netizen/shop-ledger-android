# 1.3.2 验证记录

日期：2026-10-23（北京时间）。版本名称1.3.2，versionCode 8。正常应用包名cn.shopledger，独立真机测试包名cn.shopledger.devicetest。未发布GitHub新版本。

## 手势、阻尼与触感

将AndroidView原生滚轮改为直接处理Compose指针事件的三行滚轮，在Initial阶段接管从按下到抬起的完整手势。拖动中的数值更新不重启事件处理；斜向、滑出滚轮区域、到达0.5和999.0边界时仍消费事件，防止外层记账列表接管。滚轮之外的记账页面继续正常滚动。

滑动倍率0.75，格位过半时换挡，抬手后短距离弹簧回正，无自由长距离甩动。输入框仍可手输0.1至999、最多一位小数；例如1.3的当前值保持1.3，邻项为1.0和1.5。操作滚轮本身不写账，点加号才保存。

设置新增“次数滚轮震动”：关闭、轻、中、强，默认轻，选择后立即保存，可试震。关闭后滚轮不震动，系统关闭触感或没有马达时也跳过。触感最短间隔40ms，优先用支持的TICK原语，其他设备使用8/12/18ms短震并按马达支持调幅。该设置为设备偏好，数据库仍为4。
