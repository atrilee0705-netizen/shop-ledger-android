# 1.3.0 小数次数验证记录

日期：2026-10-23（北京时间）。版本：1.3.0 / versionCode 6（滚轮内嵌调整）。**本次仅电脑验证，未连接手机、未覆盖安装、未发布GitHub新版本。**

## 功能和金额规则

- 手输0.1至999次，最多一位小数。支持0.5、1.3、1.5；多位小数、零、负数和超出范围不能保存，保留原输入供用户修改，不偷偷截断或舍入次数。
- 原生NumberPicker常驻次数输入框右侧，上下滑动每格0.5次（0.5、1.0、1.5……999.0），无需打开菜单或确认。手输1.3等非0.5整倍数时保持当前值，并显示相邻的标准0.5步长选项。滑动只填写次数，仍须点加号才记账；滚动未停稳时暂不可提交。原弹窗和“滚轮选次数”入口已移除。
- 非默认次数在保存前显示本次工资和店铺收入。38元/次时，0.5次为19元，1.5次为57元。
- 次数以整数十分之一次存储，不用浮点数。整数部分保持独立1次记录，余下小数单独保存；1.5次为1次和0.5次两条明细。员工卡片、任务累计、区间查询及结账合计按真实次数求和，不再用记录条数当次数。
- 工资和收入快照仍保存历史单价，每条金额按单价乘次数后四舍五入到分；SQL日统计、Kotlin明细、工资单和备份校验规则一致。例如0.01元/次的1.5次按0.02元计。多条不足1分的记录各自舍入，合计可能与将次数合并后一次舍入有差异。
- 已结账日期补记小数会修正原工资单、员工合计和修订记录，不计入下一期待结账工资。
